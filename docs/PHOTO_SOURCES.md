# पुणे गणपती दर्शन — छायाचित्रे व परवाना नोंदी (Photo Sources & Licensing)

हे दस्तऐवज पुणे गणपती दर्शन ॲप्लिकेशनमधील सर्व ९ गणपतींच्या छायाचित्रांचे मूळ स्रोत, परवाने (Licenses) आणि पुनर्वापर अटींची नोंद ठेवण्यासाठी आहे.

सर्व छायाचित्रे अधिकृत, मुक्त व सार्वजनिक पुनर्वापरासाठी कायदेशीररीत्या अनुमत (Creative Commons / Public Domain) अशा विश्वसनीय स्रोतांतून (Wikimedia Commons) घेतलेली असून, स्थानिक पातळीवर कार्यक्षम वेब परफॉर्मन्ससाठी WebP फॉरमॅटमध्ये ऑप्टिमाइझ केलेली आहेत.
